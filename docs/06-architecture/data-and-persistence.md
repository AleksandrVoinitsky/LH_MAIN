# Данные и PostgreSQL

## Правила

- PostgreSQL хранит постоянные данные, но не состояние тиков активного матча.
- Схема меняется только через версионированные миграции, применяемые контейнером backend до запуска API.
- Локальная разработка использует отдельный Docker volume; тесты используют отдельную временную БД.

## Минимальные домены

`users`, `password_credentials`, `player_profiles`, `inventory_items`, `match_queue_entries`, `match_sessions`, `match_participants`, `match_results`, `reward_transactions`.

## Целостность

- Пароли хранятся только как адаптивный безопасный хеш.
- Награда записывается одной транзакцией вместе с отметкой обработанного результата матча.
- Повторная доставка одинакового результата не должна начислить награду дважды.
- Удаление и изменение схемы требуют резервной копии и проверенной процедуры отката.
