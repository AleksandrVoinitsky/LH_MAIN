# Развёртывание разработки

## Docker Compose

Compose поднимает `postgres`, `backend-api`, `game-server-1`, `game-server-2` в одной внутренней сети. Конфигурация секретов передаётся через локальный неотслеживаемый файл окружения; значений по умолчанию для production-секретов нет.

## Unity server

Образ game-server собирается из Linux headless Unity build. Образ содержит только сборку и runtime-зависимости, запускается без редактора Unity. Каждый сервер публикует health/ready-сигнал и принимает не более одного матча.

## Проверки

- У каждого контейнера есть health check.
- Backend не назначает unhealthy или занятый сервер.
- Локальная команда запуска и команда остановки описываются в корневом README после реализации фазы 00.
- Логи контейнеров структурированы и содержат correlation ID, match ID и player ID без секретов.
