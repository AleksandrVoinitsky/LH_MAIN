# Фаза 08: Мета-игра

## Цель

Развить постоянный профиль в лобби: инвентарь, исследования, ресурсы и подготовку к матчу.

## Входит

- Модель аккаунтного склада, персонажей, ресурсов и разрешённых перемещений предметов.
- Прогрессия, исследования и серверные транзакции.
- API лобби/группы в границах подтверждённых сценариев.
- Аудит изменений экономики.

## Не входит

Реальные платежи, торговля за реальные деньги, лутбоксы и премиальные акции.

## Порядок

1. Согласовать единый словарь опыта и ресурсов из существующей документации.
2. Написать транзакционные тесты перемещения, списания и повторной команды.
3. Реализовать склад и подготовку к матчу.
4. Реализовать исследования и запись аудита.
5. Интегрировать получение матча с допустимым loadout.

## Готово, когда

Постоянные предметы не дублируются, экономические команды атомарны и имеют аудит, а матч получает только разрешённую подготовку.

## Агент может делать без согласования

Реализовывать бесплатные серверные доменные правила; платежи и торговля требуют отдельного решения.
