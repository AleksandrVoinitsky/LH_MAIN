# Фаза 03: Матчевый контур

## Цель

Связать авторизованного клиента с одним из двух свободных dedicated server через очередь и защищённый match ticket.

## Входит

- Очередь и session metadata в PostgreSQL.
- Резервирование свободного здорового server-slot с защитой от двойного назначения.
- Match ticket, проверка ticket Unity server и статусы матча.
- Клиентский технический flow: login -> очередь -> назначение -> FishNet connection.

## Не входит

Полный лобби UI, динамический Docker allocation, бой и награды.

## Порядок

1. Зафиксировать OpenAPI и внутренний ticket контракт до кода.
2. Написать интеграционные тесты параллельного резервирования одного слота.
3. Реализовать enqueue/status/cancel и транзакционное резервирование.
4. Реализовать одноразовую проверку ticket server-side.
5. Прогнать два клиента через разные server-slot и проверить отказ по просроченному/повторному ticket.

## Готово, когда

Авторизованный клиент подключается только к назначенному серверу; один ticket нельзя использовать повторно; занятый сервер не назначается второму матчу.

## Агент может делать без согласования

Добавлять контракты и технический клиентский flow, но не менять авторизацию и Docker-модель без нового решения.
