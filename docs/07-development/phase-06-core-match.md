# Фаза 06: Основной матч

## Цель

Добавить серверно-авторитетные системы зоны, лута, инвентаря, оружия, гранат и эффектов.

## Входит

- Конфигурируемые spawn points без создания карты.
- Серверный loot ownership, ограниченный инвентарь и транзакции подбора.
- Оружие, урон, боеприпасы, гранаты и эффекты через data-driven конфигурации.
- Сужающаяся зона и правила её урона.

## Не входит

Модели оружия, финальный баланс, премиальный контент, транспорт и ИИ.

## Порядок

1. Зафиксировать data schemas и события для предметов/эффектов.
2. Написать тесты конкурирующего подбора, вместимости, серверной валидации выстрела и зоны.
3. Реализовать системы в порядке: инвентарь -> лут -> оружие -> эффекты -> зона.
4. Проверить повторы RPC, disconnect во время предметной транзакции и завершение матча.
5. Нагрузочно проверить 64 игрока с техническим набором предметов.

## Готово, когда

Все изменения предметов и урона авторитетны на сервере, настройки отделены от контентных ассетов, а конкурирующий лут не дублируется.

## Агент может делать без согласования

Создавать кодовые конфигурации и технические заглушки; финальные списки и баланс контента не изменять.
