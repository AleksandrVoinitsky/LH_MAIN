# Фаза 01: Backend и постоянные данные

## Цель

Реализовать минимальную постоянную идентичность игрока и профиль через ASP.NET Core и PostgreSQL.

## Входит

- Миграции пользователей, credentials и профилей.
- Dev-login по логину/паролю, безопасный хеш, JWT и авторизованный профиль.
- Health/readiness checks, корреляция запросов и интеграционные тесты с PostgreSQL.

## Не входит

Email, восстановление пароля, платежи, инвентарь, очередь и Unity-подключение.

## Порядок

1. Спроектировать миграции и репозитории с тестовой PostgreSQL БД.
2. Зафиксировать failing тесты для неверного пароля, истёкшего JWT и недоступного профиля.
3. Реализовать credential hashing, login и profile endpoint.
4. Проверить миграцию на пустой БД и повторный запуск без потери данных.
5. Добавить документацию OpenAPI и проверить Compose-сценарий.

## Готово, когда

Пользователь может войти, получить JWT и свой профиль; неверный вход не раскрывает данные; миграции и интеграционные тесты воспроизводимы.
