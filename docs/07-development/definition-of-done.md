# Единые критерии готовности

Фаза завершена только если выполнены все применимые пункты:

1. Код соответствует документу фазы и не расширяет её границы.
2. Есть автоматические тесты для новой серверной/доменной логики; сначала зафиксирован воспроизводимый неуспех, затем успешный результат.
3. Backend и сервисные изменения проверены сборкой, тестами, миграциями и Compose-сценарием.
4. Unity-изменения проверены в требуемой версии Unity; сетевые изменения проверены реальным подключением.
5. Нет секретов, `Library`, `Temp`, `obj`, `bin`, IDE-артефактов и сгенерированных проектов в Git.
6. Контракты, конфигурация и критерии нагрузки обновлены в `docs/`.
7. Есть лог/метрики для диагностики отказа и health check там, где появляется контейнер.
8. `git diff --check` и целевые проверки проходят; изменения проходят review и оформляются отдельным коммитом.
