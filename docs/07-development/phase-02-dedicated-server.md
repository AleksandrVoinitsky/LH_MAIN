# Фаза 02: Unity dedicated server

## Цель

Получить контейнерный Linux headless Unity/FishNet server, готовый к назначению матча.

## Входит

- Server build target и код запуска без клиентских UI-зависимостей.
- FishNet NetworkManager и техническая тестовая сцена.
- Dockerfile для Linux build/runtime и Compose-профиль двух game-server контейнеров.
- Ready/health-сигнал, статус `idle`/`reserved`/`running`/`failed`.

## Не входит

Очередь, ticket, персонаж, бой и карта.

## Порядок

1. Добавить минимальный server bootstrap и тестовую сцену с техническими объектами.
2. Проверить Linux headless build в CI/локальном Docker-совместимом окружении.
3. Собрать runtime-образ без Unity Editor.
4. Запустить два контейнера, проверить логи, ready и изолированные сетевые порты.
5. Проверить штатное завершение и повторный запуск каждого контейнера.

## Готово, когда

Два независимых Linux headless FishNet server стартуют через Compose, сообщают здоровье и не содержат конфиденциальных конфигураций в образе.

## Агент может делать без согласования

Менять только техническую server-сцену и build/deployment код; контентные сцены не создаются.
